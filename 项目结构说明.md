# stock\_monitor 项目结构说明

> 生成日期：2026-10-19（2026-10-20 更新：重构为 **T 子系统 / 量化子系统 / 公共系统** 三层结构）
> 说明：本文档描述当前工作区的实际目录结构与各模块职责，便于快速定位代码。

***

## 一、项目定位

一个「A 股单机量化工作台」，内部共存 **4 套互相隔离的子系统**，并收敛为三层结构：

| 分层          | 包                                                | 入口                                                      | 说明                                                               |
| ----------- | ------------------------------------------------ | ------------------------------------------------------- | ---------------------------------------------------------------- |
| **T 子系统**   | `ttrade/`                                        | `python ttrade/main.py`（start.bat / start.ps1）          | 单进程常驻，交易时段每 60 秒拉行情，做T信号 → DeepSeek 守门 → 模拟成交 → 微信推送             |
| **量化子系统**   | `quant/`                                         | `python quant_daily.py`                                 | 以持仓快照为期初的纸面账户，v2.2 双模策略日频自动交易 + 复盘日报 + 看板，每日 15:01 由 stop.ps1 触发 |
| **公共系统**    | `common/` `core/` `backtest/` `lab/` + 三份 config | `python run_backtest.py`（回测） / `python run_lab.py`（实验室） | 行情/通知/费用、指标与信号核、回测、实验隔离区、配置、报表与数据目录                              |
| **公共命令行工具** | `holdings_editor.py`                             | `python holdings_editor.py`                             | 网页维护母表 `mystock_test.csv`，并一键分发到两子系统持仓文件                         |

**两子系统在代码上完全分离**：T 专属代码全部收在 `ttrade/` 包；量化专属代码全部收在 `quant/` 包；两者只在 `common/`（行情/通知/费用）、`core/`（指标 + v2.2 双模信号状态机）这两个公共包上交汇。

**持仓数据分离**：母表 `mystock_test.csv`（根目录，仅由你 + 编辑器维护）→ 一键分发到 `data/ttrade/holdings.csv` 与 `data/quant/holdings.csv`；两子系统初始化只读各自那份，**任何时候都不读/写母表**。

## 三、各目录职责详解

### 1. `common/` — 公共基础层

被两套系统共同依赖，是唯一实现处（避免口径漂移）。

| 文件                                                                         | 职责                           | 关键接口                                          |
| -------------------------------------------------------------------------- | ---------------------------- | --------------------------------------------- |
| [notify.py]()                                                              | PushPlus 微信推送 + HTML 着色、表格生成 | 推送入口、`table()`（深蓝灰表头 `#3f4a5a` + 白字，深浅色模式均可读） |
| [quotes.py](file:///d:/trae_projects/stock_monitor/common/quotes.py)       | 东方财富行情与 K 线，多节点容错 + 腾讯回退     | 实时行情、个股日 K、分钟 K、板块榜/成分股、通用磁盘缓存                |
| [fees.py](file:///d:/trae_projects/stock_monitor/common/fees.py)           | **交易费用模型唯一实现**               | 佣金/印花税/过户费、ETF 豁免判断，被做T模拟盘与回测共用               |
| [textparse.py](file:///d:/trae_projects/stock_monitor/common/textparse.py) | 通用文本/数值解析                    | `today_str()` / `_parse_money()` / `_f()`     |

关键设计：K 线数据源为「东财优先 → 连续失败 3 次熔断 900 秒 → 期间直走腾讯」。腾讯日 K 为前复权，与东财 `fqt=1` 口径一致；腾讯不提供成交额，用量×均价近似。
